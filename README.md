# Lower Fraser Flood Attenuation & Benefiting Areas

Regional adaptation of Duarte et al. (2024, *Ecosystem Services*) for **Metro Vancouver (MVRD)** and **Fraser Valley (FVRD)**, developed as part of the UBC Sustainability Scholars 2026 project #2026-030.

This R pipeline maps potential runoff retention by upstream natural ecosystems, identifies downstream beneficiaries, and ranks sub-basins by realized benefit. Full methodology and results are documented in the accompanying technical report.

## Pipeline

Scripts run sequentially (`01` through `13`), each sourcing `R/00_setup.R` and reading raw data via `data_path("layer_id")` resolved from `data_sources.csv`.

```
R/
├── 00_setup.R                libs, paths, CRS/grid helpers, data_path()
├── 01_aoi.R                  upstream + downstream areas of interest
├── 02_subbasins_fwa.R        BC FWA assessment watersheds + US transboundary (WBD HUC12)
├── 03_lulc.R                 land cover (NALCMS 2020, AAFC ACI)
├── 04_soils_hysog.R          hydrologic soil groups (HYSOGs250m)
├── 05_dem_slope.R            slope from Copernicus GLO-30 DEM
├── 06_precipitation.R        precipitation scenarios (PCIC PRISM, ECCC RDPA)
├── 07_floodplains.R          floodplain extent (JRC/CEMS global river flood hazard, RP100)
├── 08_curve_numbers.R        SCS curve numbers (baseline + barren counterfactual)
├── 09_runoff_retention.R     potential runoff retention per pixel
├── 10_demand.R               downstream flood exposure (built-up + cropland)
├── 11_routing_decay.R        distance-decayed downstream demand per watershed
├── 12_realized_benefit.R     realized benefit = provision × demand, ranked
├── 13_population.R           benefiting population (Census dissemination areas)
│
├── 99_data_package.R         result GeoPackage + rasters (output/data_package/)
├── 99_interactive_map.R      interactive web map (output/interactive_map/)
```

## Data

- **`data_sources.csv`** - data registry (`id`, `local_path`, `status`, `source`, `license`). Scripts reference datasets by `id` via `data_path()`.
- **`lookup/`** - parameter CSVs (curve numbers, land cover classes)
- **`data/`** and **`output/`** - gitignored; regenerated by running the pipeline.

Raw datasets are downloaded manually and placed into `data/raw/<local_path>` as specified in `data_sources.csv`.

## Reproducibility

Key parameters are defined in `R/00_setup.R`:
- CRS: EPSG:3005 (NAD83 / BC Albers)
- Working resolution: 30 m
- Distance-decay half-life: 20 km
- Upstream flow-distance cap: 100 km
